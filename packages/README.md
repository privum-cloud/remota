# Remota installers

Prebuilt Linux packages for [Remota](../README.md). Latest version: **0.1.2** (x86_64).

| File | For | Install |
|---|---|---|
| [`Remota_0.1.2_amd64.deb`](Remota_0.1.2_amd64.deb) | Debian / Ubuntu | `sudo apt install ./Remota_0.1.2_amd64.deb` |
| [`Remota-0.1.2-1.x86_64.rpm`](Remota-0.1.2-1.x86_64.rpm) | Fedora / RHEL / openSUSE | `sudo dnf install ./Remota-0.1.2-1.x86_64.rpm` |

The portable **`.AppImage`** (runs on any Linux, no install, ~82 MB) is published on the
[Releases](../../../releases) page — it is too large to keep in the git tree.

Prefer building it yourself? See **[Build from source](../README.md#build-from-source)**.
